# Портфолио: галереи вместо ссылок

## Цель
Убрать ссылки на сайты из карточек портфолио. Вместо одного эскиза — карусель из нескольких скриншотов. Клик по эскизу открывает полноэкранный просмотр с пролистыванием страниц. Проект dnkhabits показывается в формате мобильного приложения (в рамке телефона). Наполнить галереи скриншотами 4 сайтов: rde163, myneuro, neyromarket, dnkhabits. Старые карточки заменить на эти 4.

## Что изменится для пользователя
- Карточка проекта больше не ведёт на сторонний сайт — никаких кнопок «Открыть».
- На карточке — мини-карусель (листание стрелками/точками) с несколькими экранами сайта.
- Клик по изображению → полноэкранная галерея: листание влево/вправо (стрелки, свайп, клавиатура), счётчик «3 / 8», крестик для закрытия.
- Для dnkhabits изображения показываются в рамке смартфона (вертикальный формат).
- В админке у каждого проекта можно загрузить несколько фото, отсортировать их, удалить, выбрать формат отображения (веб / мобильный).

## Технические детали

### 1. База данных (миграция)
К таблице `portfolio_projects` добавить:
- `images jsonb not null default '[]'` — массив URL скриншотов по порядку.
- `layout text not null default 'web'` — `'web'` или `'mobile'` (рамка телефона).
- `url` сделать необязательным (ссылки убираем; колонку оставляем для совместимости, в UI не используем).

`image_url` оставляем как обложку/первый кадр (для обратной совместимости и og). Гранты уже есть; новые колонки наследуют доступ.

### 2. Сбор скриншотов
Через Playwright в песочнице открыть каждый из 4 сайтов и снять несколько экранов (разные секции/страницы — главная, каталог/услуги, карточка, контакты и т.п.):
- rde163.lovable.app, myneuro.lovable.app, neyromarket.lovable.app — десктоп (ширина 1280).
- dnkhabits.lovable.app — мобильный вьюпорт (390×844), формат `mobile`.

Скриншоты загрузить в существующий публичный бакет `portfolio-images`, полученные URL записать в `images` через insert-tool (заменив текущие записи портфолио на эти 4 проекта с описаниями и тегами).

### 3. Серверные функции (`src/lib/portfolio.functions.ts`)
- `listPortfolio` / `adminListPortfolio`: добавить в выборку `images`, `layout`.
- `upsertPortfolio`: принимать `images: string[]` и `layout`, `url` сделать optional. Тип `PortfolioProject` расширить полями `images`, `layout`.
- `uploadPortfolioImage` оставить как есть (используется для каждого добавляемого фото).

### 4. Админка (`src/components/PortfolioAdmin.tsx`)
- Блок «Галерея»: загрузка нескольких изображений, превью списком, перетаскивание/кнопки вверх-вниз для порядка, удаление каждого.
- Селектор формата: «Веб-сайт» / «Мобильное приложение».
- Убрать обязательность поля «Ссылка на проект» (поле оставить скрытым/необязательным или удалить из формы).
- Первое изображение галереи автоматически становится `image_url` (обложкой).

### 5. Новый компонент галереи (`src/components/PortfolioGallery.tsx`)
Один переиспользуемый компонент:
- **Превью-карусель** в карточке: показывает изображения с листанием (стрелки + точки), клик открывает лайтбокс.
- **Лайтбокс** (полный экран): затемнённый фон, листание стрелками/свайпом/клавишами ←/→, Esc/крестик для закрытия, счётчик «N / M», блокировка скролла body.
- Поддержка `layout="mobile"`: кадры рендерятся в рамке телефона (вертикальная пропорция, скруглённые углы), `object-contain` чтобы не обрезать.
- Чистый React + Tailwind, без новых зависимостей.

### 6. Страница `/apps` (`src/routes/apps.tsx`)
- Секцию «Портфолио проектов» переписать: вместо `<a href>` с одним `img` — `<PortfolioGallery images={p.images} layout={p.layout} title={p.title} />`.
- Удалить расчёт `host`, ссылки «Открыть», вычисление `globalThis.URL`.
- Оставить заголовок, тег, описание проекта под галереей.

## Результат
Портфолио становится визуальной витриной: посетитель листает реальные экраны каждого проекта прямо на сайте, без перехода на сторонние ресурсы, а владелец управляет галереями через админку.
