# Квиз «Калькулятор ROI ИИ-сотрудника» с SSR-результатами

## Цель
Пошаговый квиз, который ведёт пользователя к расчёту окупаемости ИИ-сотрудника, а результат показывается на отдельной серверно-отрисованной (SSR) странице с уникальным URL. Такие страницы индексируются поисковиками и цитируются ИИ-поисковиками (GEO-эффект), плюс собирают long-tail трафик по нишам.

## Что увидит пользователь
1. На `/roi` — короткий квиз из 4–5 шагов (по одному вопросу на экран, с прогресс-баром):
   - Сфера бизнеса (ниша)
   - Количество сотрудников в продажах
   - Средняя зарплата сотрудника, ₽/мес
   - Заявок/обращений в месяц
   - Доля рутины, которую можно отдать ИИ (%)
2. После последнего шага — переход на уникальную страницу результата с расчётом.
3. На странице результата — экономия ФОТ, прогноз доп. лидов/заявок, срок окупаемости, и CTA «Получить точный расчёт / бесплатный ИИ-аудит» (ведёт в чат Eureka / на контакты).

## Архитектура роутов

```text
/roi                      — лендинг квиза (SSR-интро + интерактивный квиз)
/roi/result               — страница результата (SSR), параметры в URL
/roi/$sector              — преднастроенные SEO-лендинги по нишам (индексируются)
```

- **`/roi/result`** — читает параметры через search params (`?sector=...&staff=5&salary=70000&leads=500&routine=60`). Search params, в отличие от хэша, отправляются на сервер → страница рендерится на сервере с готовыми цифрами в HTML. `head()` формирует уникальные `title`/`description`/`og:*` из параметров (например: «ROI ИИ-продавца для стоматологии: окупаемость 18 дней»). Добавляется JSON-LD (`Service` + `FAQPage`).
- **`/roi/$sector`** — набор заранее заданных страниц по нишам (стоматология, автосервис, юруслуги, салоны красоты, недвижимость, онлайн-школы и т.п.). Каждая со своим H1, типовыми цифрами и расчётом, своим `head()` и JSON-LD. Это даёт стабильные индексируемые URL для long-tail и GEO (а не сотни «мусорных» комбинаций search params, которые помечаем `noindex`).

Чтобы не плодить тонкий контент: индексируем `/roi` и `/roi/$sector` (попадают в `sitemap.xml`), а `/roi/result` с произвольными числами помечаем `robots: noindex, follow` и ставим canonical на соответствующий `/roi/$sector` либо на `/roi`.

## Формулы расчёта (в отдельном модуле `src/lib/roi.ts`)
- Экономия ФОТ = (доля рутины %) × (кол-во сотрудников) × (средняя зарплата) — с учётом налогов/взносов (~1.3).
- Доп. лиды/заявки = заявки/мес × коэффициент роста конверсии по нише (берём осторожные множители из реальных кейсов сайта: ×1.5–×3).
- Срок окупаемости = стоимость внедрения / (месячная экономия + ценность доп. лидов).
- Все коэффициенты вынесены в конфиг по нишам, чтобы легко править.

## SEO / GEO
- Уникальные `head()` (title/description/og) на `/roi` и каждой `/roi/$sector`.
- JSON-LD `Service` и `FAQPage` на страницах ниш и результата.
- `breadcrumbSchema` (Главная → Калькулятор ROI → Ниша).
- Добавить `/roi` и все `/roi/$sector` в `src/routes/sitemap[.]xml.ts`.
- Ссылка на калькулятор в шапке (`SiteHeader`) и/или CTA на главной.

## Сбор лида (по умолчанию — мягкий)
Результат показывается сразу и бесплатно (это лучше для шеринга и SEO). На странице результата — CTA, открывающий чат Eureka / форму записи YClients / переход на `/contacts`. Без жёсткого «paywall». При желании позже можно добавить кнопку «Получить детальный PDF-расчёт» с формой контакта.

## Технические детали
- `validateSearch` через `@tanstack/zod-adapter` с `fallback()` для всех параметров результата (числа, enum ниши) — безопасный парсинг и типобезопасность.
- Квиз — клиентский компонент с локальным состоянием шагов; по завершении `navigate({ to: "/roi/result", search: {...} })`.
- Расчёт выполняется чистой функцией из `src/lib/roi.ts` — одинаково на сервере (SSR) и клиенте.
- Стили — только семантические токены из `src/styles.css`, в стиле существующих секций (карточки `rounded-2xl border border-border bg-surface`).
- Шапка/подвал — переиспользуем `SiteHeader` / `SiteFooter` для единообразия.

## Файлы
- `src/lib/roi.ts` — ниши, коэффициенты, формулы, типы.
- `src/components/roi/RoiQuiz.tsx` — интерактивный квиз.
- `src/components/roi/RoiResult.tsx` — отображение расчёта + CTA.
- `src/routes/roi.index.tsx` — лендинг квиза.
- `src/routes/roi.result.tsx` — SSR-страница результата.
- `src/routes/roi.$sector.tsx` — SEO-лендинги по нишам.
- правки в `src/routes/sitemap[.]xml.ts` и `src/components/SiteHeader.tsx`.

## Открытые вопросы (можно решить по умолчанию)
- Список ниш для `/roi/$sector` — предлагаю 6–8 ключевых из кейсов и спроса.
- Стоимость внедрения для формулы окупаемости — возьму ориентир от 35 000 ₽ (как в `serviceSchema`).
